Connecting an integration to Savant
  1. Download the Savant profile from the integration's card on the Mac that runs Blueprint. It's a zip: open it for a folder with the profile inside. Add the profile to your library in Blueprint's Preferences, replacing the old one. On older Blueprint, copy it into ~/Library/Application Support/RacePointMedia/systemConfig.rpmConfig/componentProfiles/ and restart Blueprint. Keep the file name: Blueprint finds a profile by it, so a renamed copy, such as "… (1).xml", gives "Component not found".
  2. Add the component in Blueprint and set its address to 127.0.0.1 (SplycedBoard runs on the Pro Host itself). HTTP profiles use port 47200.
  3. Fill in the data tables using the IDs shown in the integration's panel, then upload the configuration to the host.

Connecting an Apple TV to Savant
  1. Give each Apple TV a fixed IP (a DHCP reservation), then pair it here with Add Apple TV.
  2. In Blueprint, add one Apple TV (SplycedBoard) component per Apple TV (download the profile) and set its IP address to 127.0.0.1, port 47200 — SplycedBoard runs on the Pro Host.
  3. Inspect the component → Show → State Variables and set AppleTVAddress to that Apple TV's IP, as shown on its card above.

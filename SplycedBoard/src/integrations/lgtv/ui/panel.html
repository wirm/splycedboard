LG TV

Find LG TVs on the network, check the keycode from each TV's IP Control Setup screen, and work the TV like a remote. The keycode is what Blueprint's LG profiles call the AccessToken. TVs in the Blueprint configuration this host runs are listed with the keycode Blueprint has for them.

How to get the keycode

LG TVs don't hand the key over the network: you turn on Network IP Control in a hidden menu on the TV, and it shows the keycode. IP control needs the TV on Ethernet (not Wi-Fi). 2018 and newer TVs need the keycode; 2016–2017 ones work without it.

2021 and newer (webOS 6+: QNED, NANO, UP, UQ, OLED B1/C1 and later)

  1. Press the Settings button (cog) on the remote.
  2. Go down to All Settings and select it.
  3. Go down to General and select it.
  4. Go down until the cursor is on Network, but don't select it.
  5. Press 7 3 7 7 7 on the remote. The IP Control Setup menu opens.
  6. Set Network IP Control to On.
  7. Select Generate Keycode and write the keycode down exactly (it's case sensitive).
  8. Back in IP Control Setup, turn on Wake On LAN, so the TV can be switched on over the network.

2018 – 2020 (OLED B8/C8 through CX, SK, SM, UM, NANO 2020)

  1. Press and hold the Settings button on the remote for at least 5 seconds; the settings menu opens.
  2. Go down until the cursor is on the network item (sometimes called Connection), but don't press Enter.
  3. Press 7 3 7 7 7. The IP Control Setup menu opens. (If 73777 doesn't work, try 8 2 8 8 8.)
  4. Set Network IP Control to On.
  5. Select Generate Keycode and write the keycode down exactly (it's case sensitive).
  6. Turn on the discovery function, and Wake On LAN where the menu has it.

2016 – 2017 (UH, UJ, OLED B6/B7/C7…)

  1. On the Live TV screen, press and hold the Settings button for at least 5 seconds.
  2. When the channel banner appears at the top, enter 8 2 8 and press OK (some sets want 8 2 8 8 8).
  3. In IP Control Setup, set Network IP Control to On, and pick Yes when it asks to reboot.
  4. No keycode: leave the Keycode field here empty. Some sets also need General → Mobile TV On → Turn On Via Wi-Fi (even on Ethernet) to switch on over the network.

Then

  1. Type the keycode into the TV's Keycode field here and pick Save & test: SplycedBoard asks the TV for its MAC address with it, which only works with the right keycode.
  2. In Blueprint, inspect the LG TV, choose State Variables in the Show menu, and set AccessToken to the keycode. Upload the configuration.

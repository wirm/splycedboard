Samsung TV

Find Samsung TVs on the network, get the AccessToken Savant's IP profiles need, and work any Samsung TV like a remote. TVs in the Blueprint configuration this host runs are listed with the token Blueprint has for them.

How Samsung TVs connect, by year
YearsModelsSplycedBoardSavant
2020 and newer T, A, B, C, D, F: Q60T, QN90A, QN85B, S95C, Q7DA, The Frame LS03T… IP Control, port 1516. Request token, then pick Allow on the TV within 30 seconds. IP, with the AccessToken in Blueprint
2016 – 2019 K, M, N, R: KS8000, MU8000, Q7FN, NU8000, Q60R, The Frame LS03N… Smart View, ports 8001/8002. Request token pairs SplycedBoard's remote (Allow on the TV). IR or RS-232: no AccessToken
2014 – 2015 H, J: H6400, JU7100… The legacy remote (port 55000) on the models that have it. J models with PIN pairing can't be controlled over the network here. IR or RS-232
2010 – 2013 C, D, E, F: C8000, D7000, ES8000, F6300… The legacy remote, port 55000. Request token, then Allow on the TV. IR or RS-232

Before requesting the AccessToken (2020 and newer)

  1. Connect the TV by Ethernet: Savant doesn't recommend Wi-Fi for IP control.
  2. Turn on IP Remote: Home → Settings → All Settings → Connection → Network → Expert Settings → IP Remote → Enable.
  3. Turn the TV on and have someone at it with its remote: after Request token it asks whether to allow SplycedBoard. Pick Allow within 30 seconds.

Putting the AccessToken in Blueprint

  1. Copy the AccessToken here.
  2. In Blueprint, open the configuration, inspect the TV, choose State Variables in the Show menu, and paste it as AccessToken.
  3. Upload the configuration. SplycedBoard reads it from this host and stops warning.

Switching on over the network

Samsung TVs switch on by Wake-on-LAN, which needs the TV's MAC address. A scan finds it; in Blueprint it goes in the TV's network connection, under the IP address. Some models also need Power On with Mobile turned on (Settings → General → Network → Expert Settings).

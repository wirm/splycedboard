Sony TV

Find Sony BRAVIA TVs on the network, check the Pre-Shared Key set on each, and work the TV like a remote. Savant's Sony profiles send the key 1234, so that's what the TV needs. TVs in the Blueprint configuration this host runs are listed with the key their profile sends.

How to set the Pre-Shared Key on the TV

The key is set on the TV, not handed out by it. Menu names vary a little between years; on Google TV models these are under Settings → Network & Internet (or Home → Settings → Network).

  1. Remote Start → On (Network → Remote Start). This lets the TV be switched on over the network.
  2. Home network setup → IP Control → Authentication → Normal and Pre-Shared Key.
  3. Home network setup → IP Control → Pre-Shared Key → 1234.
  4. Remote device settings → Control Remotely → On.

If IP control stopped working after a firmware update (the TV answers 403), the update may have broken the key: clear the Pre-Shared Key field completely, including a hidden space before 1234, save, then enter 1234 again.

For the antenna input to be selectable over IP: Home → Settings → External Inputs → Customize TV key → Channels.

Then

  1. Enter the same key here and pick Save & test. SplycedBoard reads the TV's model and MAC address with it, which only works with the right key.
  2. Blueprint needs nothing more: the key is written into Savant's Sony profiles.
